# UI design improvements
_Exported on 23.09.2026 at 15:00:18 GMT+4 from Cursor (3.19.13)_

---

**User**

Приведи UI на фронте в порядок: аккуратная вёрстка, единые отступы/типографика, понятные таблицы/карточки.
Без тяжёлых UI-kit и без лишней анимации (но не совсем простые стили). Главное - читаемо и удобно для демо ролей.

---

**Cursor**

Сначала посмотрю текущую структуру фронта и стили, чтобы привести вёрстку к единому аккуратному виду под демо ролей.

Стилей нет — добавлю дизайн-токены и аккуратно обновлю разметку под демо ролей.

Проверю, не сломал ли конец CSS при правке, и уберу inline-стили.

UI приведён в порядок без UI-kit: своя CSS-система на токенах.

**Что изменилось**
- Единый shell: шапка + навигация + контент с общими отступами
- Переключатель роли заметнее; бейджи **Директор / Руководитель / Рабочий**
- Карточки и таблицы с читаемой типографикой (IBM Plex Sans/Mono)
- Статусы ЗН цветными бейджами; финансы в карточке выделены отдельно
- Формы действий и поиск авто приведены к одним кнопкам/инпутам

Сборка проходит. Обнови `npm run dev` и пробегись по id 1–6 — особенно сравнение director (суммы + действия) и worker (без сумм).
