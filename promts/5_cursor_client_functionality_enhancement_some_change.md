Разберу текущую структуру клиентов, выручки и ролей, чтобы добавить drill-down и плитки KPI в том же стиле.

Добавляю маршруты клиента/авто и KPI-полосу на дашборде в существующем стиле.

Готово. Кратко по изменениям:

### 1. Клиент → авто → ЗН
- `/clients` — имя клиента и госномер кликабельны
- `/clients/:id` — карточка клиента и список его авто
- `/clients/:id/vehicles/:vehicleId` — авто и связанные заказ-наряды  
Доступ только у директора и руководителя (рабочий по-прежнему редиректится с `/clients`).

### 2. KPI-полоса на дашборде
Над блоком «Филиалы — выручка», только для `director` / `branch_manager` (у руководителя — по своему филиалу из ACL):

| Плитка | Логика |
|--------|--------|
| Выручка сети/филиала (факт) | Σ `total_labor_amount` по `closed` (без запчастей) |
| Средний чек | выручка ÷ число closed |
| В работе | Σ labor по незакрытым (до `delivered`) |
| Просроченные | число ЗН в `in_progress` / `waiting_parts` старше 7 дней |

Таблица по филиалам без изменений: там по-прежнему `total_amount` по `closed`.

В демо-seed почти нет `closed` и нет ЗН старше 7 дней — факт/средний чек/просрочка могут быть нулевыми, «В работе» должно показать цифры.
