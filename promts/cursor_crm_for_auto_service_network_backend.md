## Почему это интересно

Обычный CRM (лиды → сделки → «закрыто») для СТО слабоват: деньги лежат не в «сделке», а в **визите → заказ-наряде → оплате / повторном визите**.  
Сеть мастерских даёт то, чего нет у «одной точки»: сравнение филиалов, эскалации директору, единые тарифы vs локальная реальность.

Для ревьюеров это плюс: видно, что вы понимаете **операционный бизнес**, а не нарисовали абстрактный sales CRM.

## Живая воронка (не абстрактная)

| Этап | Что происходит | Деньги / конверсия |
|------|----------------|-------------------|
| Лид / звонок | Запись, «нужен осмотр», «шумит», «ТО» | % записанных с звонка |
| Визит / приёмка | Диагностика, согласие на работы | % визитов → заказ-наряд |
| Заказ-наряд (ЗН) | Работы, запчасти, статус, мастер | Средний чек, маржа, срок |
| Согласование / допы | Звонок клиенту «нашли ещё…» | Upsell % |
| Выдача + оплата | Факт денег | Выручка, просрочка оплаты |
| Повтор / retention | Напоминание ТО, гарантия, NPS-касание | LTV, повтор за 90 дней |

Воронка в UI: **Звонок → Визит → ЗН → Оплата → Повтор**, а не «Lead / Qualified / Won».

## Что реально реализовать в CRM

**Клиент (авто + человек)**  
Карточка: контакты, авто (VIN/госномер/марка), история визитов, ЗН, звонков, долгов. Поиск по номеру авто — must-have для СТО.

**Касания**  
Звонки, задачи («перезвонить по согласованию»), визиты в календаре филиала, напоминания ТО.

**Операционка**  
Заказ-наряды со статусами (диагностика → согласование → в работе → готов → выдан), позиции работ/запчастей, тарифы/прайс, мастер/пост.

**Деньги (живой дашборд)**  
Не «число лидов», а: выручка за день/неделю, конверсия звонок→визит, визит→ЗН, средний чек, загрузка постов, % просроченных ЗН, долги, сравнение филиалов.

**Команда**  
- Директор сети: все филиалы, план/факт, проблемные точки  
- Руководитель СТО: своя точка, смена, ЗН, касса дня  
- Мастер/приёмщик: свои ЗН, задачи, клиенты (без финансов сети)

## На что обратить внимание (чтобы не раздуть)

1. **Одна ось правды** — заказ-наряд. Сделка = оболочка; деньги и статусы живут в ЗН.  
2. **Авто = актив клиента** — без госномера/VIN карточка бесполезна.  
3. **Роли режут данные**, не только меню: мастер не видит маржу сети; директор не тонет в деталях поста.  
4. **Филиал в каждом объекте** — клиент может ездить по сети; ЗН всегда привязан к точке.  
5. **Конверсии с денежным исходом** — каждая метрика ведёт к ₽ или % в ₽.  
6. **Для теста (~8 ч)** не стройте склад/бухгалтерию/1С. Достаточно: клиенты+авто, воронка касаний, ЗН как «сделка», задачи, дашборд, 3 роли.
